# 计算模型

## 状态

状态由当前等级和当前等级内经验组成：

```text
state = (level, exp)
```

等级范围为0至14，经验以100为粒度，范围为0至2900。

## 动作

每次动作选择R、SR或SSR工具，并消耗10个同品质工具：

- R：增加200经验。
- SR：增加500经验。
- SSR：增加1000经验。

## 转移

- 普通结果：增加对应经验并按3000经验升级。
- 大成功：直接跳到下一节点5、10或15级。
- 到达节点时，溢出经验清零。

## 纯工具期望

对单一工具和单个阶段使用递推：

```text
E(s) = 1 + (1 - p(s)) × E(normal(s))
```

其中大成功会结束当前阶段，因此成功分支的后续阶段成本为0。0至15总期望等于0至5、5至10和10至15三个阶段之和。

## 库存优化

程序使用动态规划生成价格策略，再通过对偶列生成和策略混合，在三种库存约束下最大化期望完整强化次数。

混合策略表示一组确定性策略的凸组合。页面显示的百分比代表当前状态下各材料在最优混合策略中的权重。
