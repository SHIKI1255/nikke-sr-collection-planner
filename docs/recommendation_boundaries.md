# 推荐逻辑与边界

## 程序优化的目标

当前程序最大化的是：

> 当前等级、经验、可执行库存和目标节点下的期望完整强化次数。

它不是在最大化单次必定完成概率，也没有自动预测未来材料收入。

## 混合策略

例如页面显示：

```text
R 60% · SR 40%
```

表示长期或重复决策中的混合比例，不表示每次都必须使用R。圈是当前占比最高的材料，三角仍是有效混合策略的一部分。

每次执行后重新计算，可以根据实际库存和随机结果不断修正计划。

## 未纳入目标函数

- 未来个突、活动、派遣或协同作战收入。
- 不同材料的主观稀缺价值。
- 指定置信水平下的安全库存。
- 单次强化的保证完成概率。
- 账号内其他收藏品的并行材料需求。

需要处理这些目标时，应新增明确的情景或目标函数，而不是修改现有结果的文字解释。
