# 数据更新指南

## 更新原则

1. 优先核对游戏内当前说明。
2. 记录来源URL、核对日期和来源等级。
3. 不覆盖旧规则集；重大变化应新增日期版本。
4. 同步更新页面常量、JSON规则集和回归测试。
5. 重新核对0至15、5至15和两个历史方案。

## 必须检查

- 每次消耗数量。
- 三种工具经验值。
- 15个等级的大成功率。
- 每级经验需求。
- 大成功跳转规则。
- 节点溢出经验规则。
- 个突箱子数量、概率和单次产量。

## 发布要求

数据更新PR必须说明：

- 旧值和新值。
- 来源与核对日期。
- 是否为游戏内直接确认。
- 哪些回归结果发生变化。
- 是否需要更新页面底部数据基线。
