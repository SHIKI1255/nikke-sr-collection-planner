# 使用说明

## 1. 输入库存

输入后台显示的R、SR、SSR保养工具实际个数。计算器每10个工具视为一组可执行强化，不足10个的余数会保留。

如需长期保留材料，可展开“高级设置：保留库存”填写不参与规划的数量。

## 2. 输入状态

- 当前等级：SR收藏品现有等级。
- 当前经验：当前等级内的经验，按100经验粒度输入。
- 目标节点：5、10或15级。

R15转移得到SR5时，应输入当前等级5、经验0，而不是继续使用0至15的固定方案。

## 3. 查看结果

- 预计完整强化容量：当前库存能支持的期望完整次数，可出现小数。
- 当前建议用料：当前状态下的最优混合策略。
- 单次完成的期望消耗：按当前最优策略折算的平均材料需求。
- 库存瓶颈：最先限制完整强化次数的材料。

## 4. 执行并重算

选择实际使用的材料，然后记录普通结果或大成功。页面会：

1. 扣减10个对应工具。
2. 更新等级和经验。
3. 保存执行记录。
4. 按剩余库存重新计算。

如记录错误，可使用撤销。

## 5. 注意

结果属于概率期望，不保证单次强化一定按显示数量完成。不要长期静态照表执行，应在每次强化后记录实际结果。
